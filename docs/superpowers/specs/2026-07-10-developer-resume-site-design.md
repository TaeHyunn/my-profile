# 채용 지원용 개발자 이력서 사이트 설계

## 목표

원티드 PDF 이력서처럼 짧은 시간에 경력과 기술 역량을 파악할 수 있는 한국어 단일 문서형 웹 이력서를 만든다. GitHub 커밋 이력에서 확인된 작업만 사용하며, 웹 열람과 A4 PDF 저장 모두에서 같은 정보 위계를 유지한다.

## 디자인 방향

- 사진, 다크모드, 대형 히어로, 제품 연결 다이어그램, 스크롤 등장 애니메이션을 제거한다.
- 흰색 바탕, 검정에 가까운 본문, 한 가지 파란색 강조색만 사용한다.
- 최대 폭 920px의 단일 칼럼 문서로 구성하고, 카드 대신 구분선과 여백으로 계층을 만든다.
- 상단에는 이름, 지원 직무, 이메일, GitHub, PDF 저장 버튼을 배치한다.
- 모바일에서는 모든 정보가 한 열로 자연스럽게 쌓이고 가로 스크롤이 생기지 않아야 한다.

## 정보 구조

1. 기본 정보: 조태현, Vue 프론트엔드 개발자, 연락처
2. 소개: 여러 사용자군의 운영 제품을 Vue로 개발·운영한 강점
3. 기술: Vue 생태계, 서버 상태·폼, 모바일 웹뷰·실시간, 품질·배포
4. 경력: 샘물정보통신 / 프론트엔드 개발자 / 2025.03–현재
5. 주요 프로젝트: 최신순, 문제–구현–효과 중심
6. 학력 및 자격: 한라대학교 컴퓨터공학과 4년제 졸업, 정보처리기사

## 프로젝트 우선순위

TypeSafe Jev 평가와 커밋 증거를 함께 사용한다. Jev 점수는 선별 참고값이며 사실 근거는 커밋 분석으로 제한한다.

- 2026.04–08: 관리자 운영 안정화 및 공통 구조 개선
- 2026.04–06: 입주민 안면인식·네이티브 카메라
- 2026.02–04: 입주민 소방 자가점검
- 2025.12–2026.03: 관리비 시각화와 캐시·상태 동기화
- 2025.09–2026.02: 상가 서비스 인증·차량 운영 연결
- 2025.03–09: 주차 운영, 자동로그인, 경비원 실시간 대응

세부 항목에는 관리자웹 미출차·입출차·동기화, 입주민앱 자동로그인·상가 진입, 경비원웹 LPR·미정산 WebSocket·음성 알림, 다중 이미지, 폼·Mutation 표준화를 반드시 포함한다.

## 동작과 접근성

- PDF 저장 버튼은 `window.print()`를 호출하며 인쇄 시 숨긴다.
- 섹션 링크는 고정 헤더에 가려지지 않도록 스크롤 여백을 둔다.
- 문서 순서와 시맨틱 heading 순서를 일치시킨다.
- 모든 링크에 키보드 포커스 표시를 제공한다.

## 인쇄

- A4, 14mm 여백, 흰색 배경으로 출력한다.
- 프로젝트 항목은 가능한 한 페이지 중간에서 잘리지 않게 한다.
- 내비게이션과 PDF 저장 버튼은 인쇄에서 제외한다.
- 링크는 색상에 의존하지 않으며 실제 URL을 별도 출력하지 않는다.
